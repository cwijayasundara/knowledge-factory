The knowledge factory

Agents that do the work notice what they don't know. A separate curator agent fixes the knowledge, humans approve it, and the next run starts smarter.

1. Working agents flagAutoRCA calls kf_flag when knowledge is missing or wrong.
2. A curator agent fixesIt re-derives claims from raw sources and proposes a branch, never writing "verified".
3. A knowledge store holdsOKF concepts and SKILL.md skills in git, reviewed before merge.
